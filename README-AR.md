# Jeans House Hamburg — GitHub Pages

## الملفات التي ترفعها إلى GitHub
ارفع **كل محتويات هذا المجلد** كما هي، بما فيها مجلد `assets`.

## الخطوات
1. افتح github.com وسجّل الدخول.
2. اضغط `+` ثم `New repository`.
3. اكتب اسم المستودع: `jeans-house-hamburg`.
4. اختر `Public` ثم `Create repository`.
5. اضغط `uploading an existing file`.
6. اسحب كل الملفات والمجلد `assets` إلى الصفحة.
7. اضغط `Commit changes`.
8. افتح `Settings` ثم `Pages`.
9. عند `Source` اختر `Deploy from a branch`.
10. اختر `main` و `/ (root)` ثم `Save`.

الرابط سيصبح تقريباً:
`https://USERNAME.github.io/jeans-house-hamburg/`

## مهم
`index.html` لازم يبقى بهذا الاسم لأنه الصفحة الرئيسية.
مجلد `assets` يحتوي صورة شعار المحل، فلا تحذفه.
